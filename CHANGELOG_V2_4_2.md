# V2.4.2

Small Gemini model-selection update.

- Added a discrete model slider to **Reports (AI-enabled)**.
- Default model is now **Gemini 3.5 Flash-Lite** (`gemini-3.5-flash-lite`).
- Available stable options: Gemini 3.5 Flash-Lite, 3.5 Flash, 3.6 Flash, and 3.7 Flash.
- Model IDs are selected from an allowlist instead of free-text entry, preventing accidental invalid model names.
- Gemini API keys remain session-only and are never saved by the app.
- Report prompting, privacy filtering, low-thinking setting, PDF layout, and two-page limit are unchanged from V2.4.1.
