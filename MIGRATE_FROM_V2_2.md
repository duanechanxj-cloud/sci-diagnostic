# Moving from V2.2 to V2.3

Keep V2.2 as a backup. Unzip V2.3 into a separate folder and open that folder in VS Code.

V2.3 changes the pupil identity model, so do not copy V2.2 live Form manifests or response files into V2.3.

Safe items to reuse later if desired:

- your approved `data/question_bank/master_question_bank.csv`;
- your curriculum master if you intentionally updated it.

Create a fresh `.venv` inside V2.3. This keeps the two project versions independent while you test the new workflow.
